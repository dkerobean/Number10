# Behavior Notes

- Header remains visible and gains stronger background/border on scroll.
- Main text blocks enter with staggered fade-up movement.
- Cards and images reveal on scroll with a short vertical offset.
- CTA buttons use duplicated uppercase text that slides vertically on hover.
- Images scale slightly on hover.
- Gallery uses uneven heights to mimic a Framer editorial grid.
- Booking and ecommerce forms are frontend-only demo interactions.
